## Sobre o projeto

O **Bíblia Sagrada** é um aplicativo web feito em React para leitura da bíblia, com navegação por livros e capítulos, busca de versículos e acompanhamento de progresso de leitura.

## Funcionalidades

- 📖 **Leitura** — navegue por todos os livros do Antigo e Novo Testamento
- ❤️ **Favoritos** — marque versículos para revisitar depois
- 📈 **Progresso** — acompanhe sua jornada de leitura
- 🔍 **Busca** — encontre versículos, capítulos ou livros rapidamente

## Tecnologias

- React
- React Router DOM
- Tailwind CSS
- Lucide Icons

## Como rodar

\`\`\`bash
git clone https://github.com/Gumatosv/biblia-sagrada.git
cd biblia-sagrada
npm install
npm start
